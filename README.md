
# Automated API Testing Pipeline

A JavaScript-based API testing project that validates REST API responses using Jest and Axios. GitHub Actions automatically runs the test suite on pushes and pull requests.

## Tech Stack
- JavaScript
- Jest
- Axios
- GitHub Actions

## Test Coverage
- HTTP status code validation
- Response structure and data type validation
- Product list validation
- Invalid resource handling

## Run Locally

```bash
npm install
npm test
```
